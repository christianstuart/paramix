## What changed

### Loop card (`res/qml/Deck/Loop.qml`)

The card now fills the 112 px transport band and is 224 px wide:

| Row | Measured height | Token |
|---|---|---|
| Header (LOOP, editable size, anchor, loop lamp) | 16 | `Theme.deckLoopHeaderHeight` (`space4`) |
| Beat sizes | 39 | `Theme.deckLoopBeatRowHeight` (derived remainder) |
| Transport (In, In-goto, Out, Out-goto, Loop, Rel/Exit, Stop) | 24 | `Theme.deckLoopActionRowHeight` (`space5`) |
| Roll (1/2, 1, 2, 4) | 24 | `Theme.deckLoopRollRowHeight` (`space5`) |
| Inset | 2 + 2 | `Theme.deckLoopInset` (`space1 / 2`) |
| Row gaps | 3 x 1 | `Theme.deckLoopRowGap` |

The beat row is a horizontal `Flickable` over 1/8, 1/4, 1/2, 1, 2, 4, 8, 16
and 32 as `beatloop_<size>_toggle`, 5 visible at a time, with `loop_halve` and
`loop_double` pinned at the ends and a 3 px scrollbar under the viewport. The
key height derives from the row, so the card fills the band at any `uiScale`.

### Pane tabs (`res/qml/Deck/DeckPaneTabs.qml`)

The vertical 34 x 112 column is gone. The selector is a 16 px horizontal
CUE / MOVE / GRID row above the pane; it keeps the same persisted values, the
GRID lock badge, accessible names and hints. The pane below it is 92 px.

### Deck (`res/qml/Deck.qml`, `res/qml/Theme/Theme.qml`)

- Transport row order is now loop card, then the pane column (tabs + pane),
  matching the approved mock.
- New deck metrics: `deckPaneTabHeight` (16), `deckPaneContentHeight` (92),
  `deckPaneMinWidth` (196), `deckLoopCardWidth` (224), the four loop row
  heights and the inset/gap. `deckPaneHeight` stays 112, so deck height
  (240), the waveform strip and the library split do not move.
- `paneTabsHeight` is removed; the old vertical tab delegate is removed.

### Gestures

| Former hidden action | New visible affordance |
|---|---|
| Right-click In (`loop_in_goto`) | Split `IN` key plus a `^` goto key |
| Right-click Out (`loop_out_goto`) | Split `OUT` key plus a `v` goto key |
| Right-click Rel (`reloop_andstop`) | Visible `STOP` key |
| Right-click a grid nudge key (fine control) | `F` (FINE) latch in the grid BPM row; while lit the six nudge keys send the fine control |
| Right-click a marker key (clear) | `C` (CLR) latch in the grid BPM row; while lit marker keys clear |
| Wheel on the loop size row | Visible 3 px scrollbar; wheel and drag remain accelerators |

The hotcue right-click color/clear popup is the one retained context action
named by the approved mock; the pads keep their accessible description.

panes at 1792/2560. The column is present from a 708 px deck and takes 135 px,

every measured pane is at or above it.
