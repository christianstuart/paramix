## Gating

`REKORDBOX_EXPORT` defaults on. The target lives in the library-export dialog,
which is built with Engine Prime support, so the UI is compiled only when both
`REKORDBOX_EXPORT` and `ENGINEPRIME` are on. The ANLZ/PDB writers and the job
are built unconditionally; only the target and the menu item are gated. With
`REKORDBOX_EXPORT=OFF`, `Mixxx.Library.rekordboxExportAvailable` is false and
the File-menu item stays disabled.

## Not covered

- No job run is started by the UI test; the job is covered by its own test
  suite.
- No overwrite/merge of an existing device export: the dialog warns and the job
  refuses.
- Hardware: loading the stick in rekordbox, checking grids/cues on a player and
  re-importing into Paramix are the owner's checks.
