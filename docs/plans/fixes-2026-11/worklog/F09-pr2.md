## Provenance / open decision

This task directed the writer to use chrisle/rbxport's `rbl-pdb` at
`d0ff75b378ec85be891d9f3067ada1e82bad4cae`. The merged F09 plan and the ANLZ
provenance say rbxport is **not a permitted input** and that the writers must be
clean-room. Both statements are recorded in `docs/rekordbox-export.md` under
"Provenance"; the integrator must confirm which direction wins before merge.

The commit's `LICENSE` and `LICENSING.md` state GPL-2.0-or-later, compatible
with this repository's GPL-2.0-only by choosing version 2. GitHub's detector
reports no licence, which is the basis of the clean-room decision. The in-tree
`lib/rekordbox-metadata/rekordbox_pdb.ksy` is the cross-check the tests use.

If the clean-room rule stands, this writer needs a rewrite from the `.ksy` and
the owner's own output; the constant browse rows need an independent source.

## Deliberately not covered

- ID allocation and mapping from Paramix tracks, artists, albums, genres and
  playlists. The writer takes numeric ids.
- `labels`, `artwork` and the history tables are empty.
- The full `RekordboxFeature` import path needs a mounted device tree and a
  database connection; the test reads back with the same Kaitai reader instead.
- Audio files, paths on the stick, the export job and the UI.

## Notes for the next PR

  `/PIONEER/USBANLZ/...` analysis path before building the track rows.

  the device name and date.
- Playlists need stable ids; entries reference track ids assigned in the same
  pass.
- Track `colorId` is the 1..8 device color row, not an RGB value.
- The MP3 timing offset remains the job's responsibility, as in the importer.
