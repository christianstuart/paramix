# F09 PR 1 — ANLZ writer worklog

- **Issue:** #67, Fixes F09 - Export to Rekordbox format
- **Branch:** `bradley/rekordbox-export-anlz`
- **Date:** 2026-11-19
- **Scope:** PR 1 of four. ANLZ writer only; no PDB, job or UI.

## What changed

- Added `src/library/export/rekordbox/rekordboxanlzwriter.{h,cpp}`.
  - `PMAI` header and section framing.
  - `PPTH` path, `PQTZ` beat grid, `PVBR` zero seek table.
  - `PCOB`/`PCO2` cue lists with hot cues, memory cues, loops and comments.
  - `PWAV`, `PWV2`, `PWV3`, `PWV4`, `PWV5`, `PWV6`, `PWV7` waveform payloads.
  - Conversions from `mixxx::Beats`, `Cue` and `Waveform`.
- Added `src/test/rekordboxexportanlztest.cpp`.
- Added `docs/rekordbox-export.md` with the format, provenance and gaps.
- `CMakeLists.txt`: the new source, the new test, and the Kaitai/rekordbox
  reader libraries linked into `mixxx-test` so the test can read files back.

## Deliberately not implemented

- `PSSI` (phrases), `PVDI` (vocals), `PQT2` (extended grid), `PWVC`, a real
  `PVBR` table, memory cue colors, active-loop detection, loop quantization
  and Intro/Outro cues. The full list is in `docs/rekordbox-export.md`.

## Notes for the next PR

- The path in `PPTH` is supplied by the caller. The job must choose between a
  full `/Contents/...` path for a stick and `?/name` for a share tree.
- Beat times are written as the grid stores them; the MP3 timing offset is
  the export job's responsibility, matching the importer.
- Cues are converted from `Track::getCuePoints()` after loading the track on
  the main thread; the writer itself is a pure function.
