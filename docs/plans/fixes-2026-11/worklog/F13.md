## What changed

### Stem lane strip (`res/qml/StemLaneStrip.qml`)

- Every row now carries a lane color key, a fixed name, an **M** key, an **S**
  key and a horizontal volume slider, all inside the ~20 px row a lane gets with
  the library visible.
- Names come from the lane position: DRUMS, BASS, OTHER, VOCALS. A stem file
  that declares a different name (for example a custom label such as "Piano",
  or vocals in a different slot) keeps its declared name; an unlabeled set uses
  the positional name.
- The volume slider is bound to `[ChannelN_StemX],volume`, with unity (1.0) at
  the right end. Double-click resets it to the control default (unity). The
  slider does not consume wheel events: the strip still swallows wheel and
  presses so the waveform never scrubs underneath it.
- The lane color key is now a status light (filled while audible, hollow while
  muted, accent-framed while soloed); the M key owns the mute toggle.
- Every key and the slider have `Accessible.name`; keys are check boxes with
  `Accessible.checkable` / `Accessible.checked` and every control has a tooltip.

### Solo

- Solo moved out of `Deck/HotcueAndStem.qml`, so `StemLaneStrip` is the single
  owner of solo state for a deck.
- The first solo captures every lane's mute state. Solo mutes every lane that is
  not in the solo set; a second solo adds to the set; removing the last solo
  restores the captured states.
- The captured states are written once, when solo starts, and are not updated by
  control changes. A mute changed from a controller during solo therefore
  cannot overwrite the state that will be restored.
- A manual M click while solo is active clears solo first (restoring the saved
  states) and then applies the edit, so a solo-forced mute is never stored as a
  previous state.
- If a new track brings fewer lanes than the solo set references, the stale
  indexes are dropped so a deck cannot be left with every remaining lane muted.

### Narrow layouts

- Below `Theme.stemLaneComfortWidth + Theme.space7` the row shows only the name,
  M and S. The volume slider appears when the row is hovered (or when the
  slider already has focus), and the label gives up the space again when the
  pointer leaves.
- The strip width in `WaveformDisplay.qml` is now capped at 42 % of the
  waveform, so a narrow deck actually reaches the compact layout instead of
  keeping a fixed 168 px overlay.

### Stem pane removal

- `Deck.Pane.Stems` and the `stemsPane` instance are gone from `Deck.qml`; the
  CUE pane is the fallback for any selection that is not Move or Grid.
- The fourth tab is gone from `Deck/DeckPaneTabs.qml`.
- `HotcueAndStem.qml` is reduced to the hotcue grid: `paneMode`, the stem tab,
  the stem lane delegate, the M/S key component, QuickFX wiring, the per-lane
  volume fader and the Acapella/Instrumental helpers are deleted.
- A stored `[Skin],deckN_pane` of 3 is mapped to Cue on load and written back so
  the stale value does not survive the next restart.

## Dropped from the UI

- Per-stem QuickFX knob, enable toggle and chain preset. The controls still
  exist for controllers and Pad FX covers per-stem effects, per the plan.
- Acapella and Instrumental shortcuts. They do not fit in a 20 px row beside
  the name, M, S and slider, and adding a strip header would cover waveform
  height that F07 owns. The mute keys cover the same result lane by lane.
