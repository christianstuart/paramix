# F09 PR 3 — export job worklog

- **Issue:** #67, Fixes F09 - Export to Rekordbox format
- **Branch:** `bradley/rekordbox-export-job`
- **Date:** 2026-11-20
- **Scope:** PR 3 of four. The worker-thread export job, request, path and ID
  allocation, audio copy, ANLZ writes and `export.pdb`; no dialog or QML action.

## What changed

- Added `src/library/export/rekordbox/rekordboxexportrequest.h`.
  - Device root, optional device name, crate and playlist selections.
  - An empty selection means the whole library plus every non-hidden playlist.
- Added `src/library/export/rekordbox/rekordboxexportjob.{h,cpp}`.
  - `RekordboxExportJob`, modelled on `EnginePrimeExportJob`: track, crate and
    playlist data are loaded on the collection thread with blocking calls.
  - Free-space preflight before copying.
  - Audio copied to `Contents/<Artist>/<Album>/<id> - <file>`.
  - ANLZ `.DAT`, `.EXT` and `.2EX` written to
    `PIONEER/USBANLZ/P<folder>/<id>/`.
  - MP3 timing offsets added to beat and cue times, using the importer's
    decoder-dependent mapping.
  - ID allocation and PDB construction in `buildPdbLibrary()`, kept pure for
    tests.
  - Staging directory under the device root, then a rename of `PIONEER` and
    `Contents` into place. An existing tree is refused rather than overwritten.
- Added `src/test/rekordboxexportjobtest.cpp`.
- Updated `docs/rekordbox-export.md` and `CMakeLists.txt`.

## Deliberate limits

- Track color is written as 0. The eight DeviceSQL color rows are names, not
  RGB values; no reliable mapping from an arbitrary Mixxx color was available.
- Playlists are exported flat. Mixxx has no playlist folders to preserve.
- The target must not already contain `PIONEER` or `Contents`. Merging into an
  existing export needs an explicit overwrite decision in the UI PR.
- The copy/staging/rename path has no automated test. It needs a temporary
  collection and is exercised manually with the UI in PR 4.
- `dateAdded`, `dateCreated`, play count, rating, bitrate, sample rate, file
  size, tempo, track number, comment, artist, album, album artist, genre and
  key are mapped. Disc number stays 0 because Mixxx has no disc-number field.
