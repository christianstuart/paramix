# F08 — DDJ-SX: load buttons and backspin (worklog)

Branch: `bradley/fix-ddj-sx` · Issue: #66 · Owner-chosen backspin gesture: **(a) throw the
platter backward and release**.

## What changed

Only the two owned files were considered; in practice all edits are in
`res/controllers/Pioneer-DDJ-SX-scripts.js`. `Pioneer DDJ-SX.midi.xml` is unchanged
(no binding needed to change).

### Load button no longer moves the headphone cue

`PioneerDDJSX.autoPFL` now defaults to `false` (was `true`). The variable is still a
documented option in the `USER OPTIONS` block at the top of the script, with the comment
updated to state the new default. The mapping has no user-settings UI, so this variable is
the only place to change it. `PioneerDDJSX.loadButton` is otherwise untouched.

### Backspin inertia after touch release

Previously `PioneerDDJSX.jogTouch` called `engine.scratchDisable(deck + 1, true)`
immediately on touch release, so the remaining platter ticks of a thrown platter were
ignored and the backspin stopped with the hand.

Now:

- On touch release, `jogTouch` schedules a one-shot
  `PioneerDDJSX.jogInertiaTimeout` timer (`PioneerDDJSX.restartScratchReleaseTimer`)
  instead of disabling scratch.
- Every platter tick handled as a scratch tick (`jogPlatterTick` and
  `jogPlatterTickShift`) refreshes that timer when it is pending
  (`PioneerDDJSX.refreshScratchReleaseTimer`). Ticks that still arrive after release
  therefore keep scratching.
- When ticks stop for `jogInertiaTimeout` ms, the timer fires and calls
  `engine.scratchDisable(deck + 1, true)` (same call and ramp flag as before).
- Touching the platter again cancels a pending timer before `scratchEnable`, so a quick
  re-touch cannot be cut off by the old release timer.
- The timer only runs after a release; while the top is still touched it is never
  started, so holding a still platter does not disable scratch.

`jogInertiaTimeout = 20` ms is copied from `Numark-Mixtrack-Pro-scripts.js`
(lines 590-591, 598-599, 635-637), which restarts a 20 ms one-shot timer on jog ticks
until they stop. The plan asked for an existing **Pioneer** mapping to copy; there is
none in `res/controllers` that implements platter inertia — no Pioneer script starts a
timer around scratch ticks at all. The Numark constant is the closest in-tree precedent
and is called out in a comment next to the constant. No new value was invented.

### Explicitly not changed

- No `engine.spinback()` call was added (gesture (b) was not requested).
- Ring nudging (`jogRingTick`, `jogRingTickShift`, `pitchBendFromJog`) is untouched.
- Slip mode (`slipButton`, `slipLed`, `slip_enabled` bindings) is untouched.
- The play-button brake (`toggledBrake`, `script.brake`) is untouched.
- Shift-jog search: `jogPlatterTickShift` keeps its pitch-bend path and shift multiplier;
  the only addition is the release-timer refresh inside its existing scratch branch.
- `Pioneer DDJ-SX.midi.xml` is unmodified.
